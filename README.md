# 好吃懒做动物园

## 运行

```sh
npm install
npm run dev
```

打开终端给出的本地地址，默认 http://127.0.0.1:5173/ 。`npm run build` 输出到 `dist/`，`npm test` 运行关键行为测试。

## 操作

- WASD 或方向键沿当前视线前进、后退、左移、右移。鼠标左键旋转视角，滚轮以鼠标位置缩放；右键或中键拖动平移。
- 右上角小地图只显示全园、动物和观察位置，不接受导航操作；可以收起。
- 点击动物选中，双击近看。近看会跟随动物，操作鼠标后立即退出跟随。底栏「大门」可查看入口。
- 按住动物拖动搬迁；远距离搬迁可先点底栏「抓取」，使用 WASD / 方向键或鼠标中键移动镜头，滚轮缩放，左键点击目标展区地面放下。Esc 取消。
- 放入任何展区均可。水中或障碍物上的落点会寻找同展区可站立位置，无合法位置则返回。
- 空格暂停 / 继续；底栏可收起。环境声是本地合成的风声。
- 鹦鹉、火烈鸟和孔雀会在展区内短距离飞行；鸟翼有分段飞羽与收翼动作，孔雀会周期性开屏。

## 技术栈与结构

React 19、TypeScript、Three.js、React Three Fiber、Drei、Vite、Vitest。模拟在浏览器本地运行，无后端，无用户数据上传。动物模型存放在 `public/models/`。

| 文件 | 职责 |
| --- | --- |
| `src/world.ts` | 物种、群体数量、地形、水池、展区轮廓、落点判断 |
| `src/navigation.ts` | 障碍避让、A* 路径与直线路径简化 |
| `src/zoo.ts` | 个体状态、食位预订、饲养员、搬迁、冲突 |
| `src/RiggedAnimal.tsx` | 静态资产骨骼化、蒙皮、步态、头尾与鸟翼动画 |
| `src/Landscape.tsx` / `src/Foliage.tsx` | 地形、路网、围栏、建筑、水面、实例化植被 |
| `src/ZooScene.tsx` | 固定步长模拟、镜头与渲染 |
| `src/Minimap.tsx` | 小地图导航、动物与冲突位置 |
| `src/App.tsx` | 抓取、交互、轻量操作栏 |

业务按每秒 30 步推进；个体拥有唯一 ID、位置、饥饿值、能量、步态相位与行为状态。食物由当前住户食谱决定，单食盆最多三个预订位。冲突经过警戒、追逐、接触攻击、退让与冷却；抓起目标立即中断对方冲突状态。没有死亡系统。
